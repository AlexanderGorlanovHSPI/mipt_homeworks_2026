# Описание проекта

Консольный ИИ-ассистент для общения с LLM через OpenAI-compatible API.
Приложение хранит историю диалога, ограничивает размер контекста, умеет
подставлять содержимое текстовых файлов в сообщения и обрабатывать большие
файлы по чанками.

## Возможности

- чат с LLM с сохранением истории;
- ограничение контекста по количеству сообщений и символов;
- конфигурация через `config.yaml` и переменные окружения;
- выход из чата по `\q`;
- очистка истории и экрана `/reset`;
- подстановка файлов с помощью `@::path/to/file::`;
- chunk-режим `/filechunk` для обработки файла фрагментами.

## Установка

Перейдите в папку проекта, создайте виртуальное окружение и установите зависимости:

```bash
cd final_project
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

`system_prompt` задается в YAML

```bash
.venv/bin/python main.py
```

## Команды

Очистить историю чата:

```text
/reset
```

Добавить содержимое текстового файла в сообщение:

```text
Проверь этот код @::/path/to/main.py::
```

Размер прикрепляемого файла ограничен `5 MB`.

Запустить обработку файла по абзацам:

```text
/filechunk
```

Обрабатывать по три абзаца:

```text
/filechunk paragraph=3
```

Обрабатывать чанки длиной 67 символов:

```text
/filechunk len=67
```

Обработать все чанки подряд без подтверждения Enter:

```text
/filechunk paragraph=3 -y
```

В chunk-режиме `\q` завершает обработку файла.
